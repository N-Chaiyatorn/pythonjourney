# What is Big O notations
Big O is a powerful tools to describe how many time and space of complexity of your algorithms is. In other words, it describe how complexity of your algorithms and performance of your algorithms
## Representation and analyse.
In big o notations it provide function be like:
```
T(n) = O(f(n))
```
The equation above will describe how much time that your algorithms takes, where n is input of algorithms and f(n) is number of operations. So it will describe how performance are change if the size of input will be change.
